# Задание 1. Базовые операции

## Задача 1. Дробная часть

### Текст задачи
Дана сигнатура метода: `public double fraction(double x);`
Необходимо реализовать метод так, чтобы он возвращал только дробную часть числа `x`.
Подсказка: вещественное число может быть преобразовано к целому путём отбрасывания дробной части.

Пример: `x = 5,25` → результат `0,25`.

### Алгоритм решения
1. Принять вещественное число `x`.
2. Привести `x` к типу `int` - при этом дробная часть отбрасывается (усечение к нулю).
3. Вычесть из исходного `x` полученное целое: `x - (int) x` - это и есть дробная часть.
4. Вернуть результат.

---

## Задача 2. Есть ли позитив

### Текст задачи
Дана сигнатура метода: `public boolean isPositive(int x);`
Метод должен вернуть `true`, если число `x` положительное.

Пример 1: `x = 3` → `true`.
Пример 2: `x = -5` → `false`.

### Алгоритм решения
1. Принять целое число `x`.
2. Сравнить `x` с нулём: если `x > 0`, вернуть `true`, иначе `false`.
3. Ноль не считается положительным числом.

---

## Задача 3. Двузначное

### Текст задачи
Дана сигнатура метода: `public boolean is2Digits(int x);`
Метод должен вернуть `true`, если число `x` двузначное.

Пример 1: `x = 32` → `true`.
Пример 2: `x = 516` → `false`.

### Алгоритм решения
1. Принять целое число `x`.
2. Взять модуль числа, чтобы корректно обрабатывать отрицательные значения.
3. Проверить, попадает ли модуль в диапазон от 10 до 99 включительно.
4. Вернуть `true`, если попадает, иначе `false`.

## Задача 4. Делитель

### Текст задачи
Дана сигнатура метода: `public boolean isDivisor(int a, int b);`
Метод должен вернуть `true`, если любое из принятых чисел делит другое нацело.

Пример 1: `a = 3, b = 6` → `true`.
Пример 2: `a = 2, b = 15` → `false`.

### Алгоритм решения
1. Принять два целых числа `a` и `b`.
2. Проверить особые случаи с нулём (деление на ноль недопустимо):
   - если оба нули - вернуть `false`;
   - если одно из чисел ноль, а другое нет - вернуть `true` (0 делится на ненулевое).
3. Проверить остатки от деления: `a % b == 0` или `b % a == 0`.
4. Если хотя бы одно условие истинно — вернуть `true`, иначе `false`.

---

## Задача 5. Равенство

### Текст задачи
Дана сигнатура метода: `public boolean isEqual(int a, int b, int c);`
Метод должен вернуть `true`, если все три полученных числа равны.

Пример 1: `a = 3, b = 3, c = 3` → `true`.
Пример 2: `a = 2, b = 15, c = 2` → `false`.

### Алгоритм решения
1. Принять три целых числа `a`, `b`, `c`.
2. Проверить равенство `a == b` и `b == c`.
3. Если оба условия истинны, значит `a == b == c` - вернуть `true`, иначе `false`.

# Задание 2. Условия

## Задача 1. Тридцать пять

### Текст задачи
Дана сигнатура метода: `public boolean is35(int x);`
Вернуть `true`, если `x` делится на 3 или на 5, но если делится на оба сразу - вернуть `false`.

Примеры: `5 → true`, `8 → false`, `15 → false`.

### Алгоритм решения
1. Вычислить два флага: `x % 3 == 0` и `x % 5 == 0`.
2. Если оба истинны - вернуть `false` (число делится на 15, что не подходит).
3. Иначе вернуть результат `d3 || d5`.

---

## Задача 2. Тройной максимум

### Текст задачи
Дана сигнатура метода: `public int max3(int x, int y, int z);`
Вернуть максимальное из трёх чисел. Идеальное решение - две `if`, без вложенности.

Пример 1: `x = 5, y = 7, z = 7` → `7`.
Пример 2: `x = 8, y = -1, z = 4` → `8`.

### Алгоритм решения
1. `max = x`.
2. Если `y > max` - `max = y`.
3. Если `z > max` - `max = z`.
4. Вернуть `max`.

---

## Задача 3. Двойная сумма

### Текст задачи
Дана сигнатура метода: `public int sum2(int x, int y);`
Вернуть сумму, но если она попадает в диапазон `[10, 19]` - вернуть `20`.

Пример 1: `x = 5, y = 7` → `20`.
Пример 2: `x = 8, y = -1` → `7`.

### Алгоритм решения
1. Вычислить `s = x + y`.
2. Если `10 ≤ s ≤ 19` - вернуть `20`.
3. Иначе вернуть `s`.

---

## Задача 4. Возраст

### Текст задачи
Дана сигнатура метода: `public String age(int x);`
Вернуть строку «<x> год/года/лет» по правилам русского языка.
«год» - если оканчивается на 1, кроме 11; «года» - на 2, 3 или 4, кроме 12, 13, 14; «лет» - во всех остальных случаях.

Примеры: `5 → "5 лет"`, `31 → "31 год"`, `44 → "44 года"`.

### Алгоритм решения
1. Взять последние две цифры: `abs = |x| % 100`.
2. Если `abs` в диапазоне `11–14` - вернуть `"<x> лет"` (исключение для 11…14).
3. Иначе взять последнюю цифру `last = abs % 10`:
   - `1` → `"год"`;
   - `2, 3, 4` → `"года"`;
   - остальное → `"лет"`.

---

## Задача 5. Вывод дней недели

### Текст задачи
Дана сигнатура метода: `public void printDays(String x);`
Вывести переданный день и все последующие до воскресенья. Если строка не день недели - вывести «это не день недели». Использовать `switch`, не `if`.

Пример 1: `"четверг"` → четверг, пятница, суббота, воскресенье.
Пример 2: `"чг"` → это не день недели.

### Алгоритм решения
1. Реализовать `switch (x)` по названиям дней.
2. В каждом `case` печатать название дня, `break` **не ставить** - благодаря fall-through автоматически выводятся все последующие дни.
3. `break` - только после `case "воскресенье"`, чтобы не сработал `default`.
4. `default` печатает «это не день недели».
5. В `Main` ввод приводится к нижнему регистру через `.toLowerCase()`, чтобы «Четверг» и «четверг» работали одинаково.

# Задание 3. Циклы

## Задача 1. Числа наоборот

### Текст задачи
Дана сигнатура метода: `public String reverseListNums(int x);`
Вернуть строку со всеми числами от `x` до `0` включительно.

Пример: `x = 5` → `"5 4 3 2 1 0"`.

### Алгоритм решения
1. Завести `StringBuilder`.
2. Если `x ≥ 0`, идти циклом `i = x; i >= 0; i--`; если `x < 0` - `i = x; i <= 0; i++`.
3. Добавлять `i` в буфер; пробел — только после всех чисел, кроме последнего.
4. Вернуть строку.

---

## Задача 2. Степень числа

### Текст задачи
Дана сигнатура метода: `public int pow(int x, int y);`
Вернуть `x` в степени `y`.

Пример: `x = 2, y = 5` → `32`.

### Алгоритм решения
1. `result = 1`.
2. Цикл `y` раз: `result *= x`.
3. Вернуть `result`.
4. При `y < 0` вернуть `0` - отрицательная целочисленная степень не представима в `int`.

---

## Задача 3. Одинаковость

### Текст задачи
Дана сигнатура метода: `public boolean equalNum(int x);`
Вернуть `true`, если все знаки числа одинаковы.

Примеры: `1111 → true`, `1211 → false`.

### Алгоритм решения
1. Взять модуль числа.
2. Если число однозначное (`< 10`) - вернуть `true`.
3. Запомнить последнюю цифру `first = x % 10`.
4. В цикле «откусывать» по одной цифре и сравнивать с `first`; при первом несовпадении - вернуть `false`.
5. Если цикл дошёл до нуля - вернуть `true`.

---

## Задача 4. Правый треугольник

### Текст задачи
Дана сигнатура метода: `public void rightTriangle(int x);`
Вывести треугольник высотой `x`, в `i`-й строке `i` звёздочек, выровненных по правому краю.

Пример (`x = 3`):
```
  *
 **
***
```

### Алгоритм решения
1. Цикл `row = 1 … x`.
2. В каждой строке вывести `x - row` пробелов.
3. Затем вывести `row` символов `*`.
4. Перейти на новую строку.

> В примере методички визуально показано вдвое больше пробелов - это артефакт вёрстки. По смыслу «по правому краю» нужно `x - row` пробелов. Если требуется точное совпадение с примером - используйте `2 * (x - row)`.

---

## Задача 5. Угадайка

### Текст задачи
Дана сигнатура метода: `public void guessGame();`
Загадать число 0…9, читать попытки пользователя, пока не угадает; по завершении вывести количество попыток.

### Алгоритм решения
1. `secret = new Random().nextInt(10)`.
2. Счётчик `attempts = 0`.
3. В бесконечном цикле: вывести подсказку (первая - «Введите число…», последующие - «Вы не угадали…»), прочитать число с валидацией (число от 0 до 9).
4. Увеличить `attempts`; если совпало - вывести «Вы угадали!» и итог с правильной формой слова «попытка», выйти.
5. Общий `Scanner` хранится в `Laboratory_Work_1`, `Main` берёт его через `getScanner()` - исключает конфликт двух буферов на `System.in`.

# Задание 4. Массивы

## Задача 1. Поиск первого значения

### Текст задачи
Дана сигнатура метода: `public int findFirst(int[] arr, int x);`
Вернуть индекс первого вхождения `x` в массив. Если элемента нет - вернуть `-1`.

Пример: `arr = [1,2,3,4,2,2,5], x = 2` → `1`.

### Алгоритм решения
1. Пройти массив от `0` до `length - 1`.
2. При первом совпадении `arr[i] == x` вернуть `i`.
3. Если цикл завершился - вернуть `-1`.

---

## Задача 2. Поиск максимального по модулю

### Текст задачи
Дана сигнатура метода: `public int maxAbs(int[] arr);`
Вернуть элемент массива с наибольшим абсолютным значением (возвращается именно значение из массива, со знаком).

Пример: `arr = [1,-2,-7,4,2,2,5]` → `-7`.

### Алгоритм решения
1. Проверить, что массив не пуст (иначе - исключение).
2. Инициализировать `best = arr[0]`.
3. Пройти по остальным элементам; если `|arr[i]| > |best|` - обновить `best = arr[i]`.
4. Вернуть `best` (исходное значение, не модуль).

---

## Задача 3. Реверс (на месте)

### Текст задачи
Дана сигнатура метода: `public void reverse(int[] arr);`
Перевернуть массив на месте.

Пример: `[1,2,3,4,5]` → `[5,4,3,2,1]`.

### Алгоритм решения
1. `left = 0`, `right = arr.length - 1`.
2. Пока `left < right`: поменять `arr[left]` и `arr[right]`, сдвинуть оба указателя к центру.
3. Метод возвращает `void` - массив изменяется по ссылке.

---

## Задача 4. Возвратный реверс

### Текст задачи
Дана сигнатура метода: `public int[] reverseBack(int[] arr);`
Вернуть новый массив, в котором значения `arr` идут в обратном порядке.

Пример: `[1,2,3,4,5]` → `[5,4,3,2,1]`.

### Алгоритм решения
1. Создать новый массив той же длины.
2. Для `i = 0 … length-1`: `result[i] = arr[length - 1 - i]`.
3. Вернуть новый массив. Исходный не изменяется.

---

## Задача 5. Объединение

### Текст задачи
Дана сигнатура метода: `public int[] concat(int[] arr1, int[] arr2);`
Вернуть новый массив: сначала `arr1`, затем `arr2`.

Пример: `[1,2,3]` и `[7,8,9]` → `[1,2,3,7,8,9]`.

### Алгоритм решения
1. Создать массив длины `arr1.length + arr2.length`.
2. Скопировать `arr1` в начало.
3. Скопировать `arr2` со смещением `arr1.length`.
4. Вернуть результат.

# Проверка ввода

Ввод данных с клавиатуры реализован во вспомогательных методах класса `Main` (`readInt`, `readDouble`, `readIntArray`) и в `readGuess` класса `Laboratory_Work_1`.

- **Целые числа** - при вводе нечисла выводится сообщение об ошибке, запрос повторяется.
- **Вещественные числа** - разрешён ввод как с точкой, так и с запятой в качестве разделителя (`5.25` и `5,25`).
- **Массивы** - элементы вводятся одной строкой, через пробел и/или запятую (`1 2 3` или `1, 2, 3`). Пустая строка - пустой массив. Некорректный элемент - запрос повторяется.
- **Угадайка** - число должно быть от 0 до 9, иначе запрос повторяется.
- **Меню** - при неверном номере пункта пользователь получает уведомление и возвращается в меню.
